# Project Purpose

This is the **moku-dev-examples** repository, a comprehensive collection of examples demonstrating how to use Liquid Instruments Moku devices across multiple programming languages and environments.

## What are Moku Devices?

Moku devices are hardware instruments from Liquid Instruments (https://www.liquidinstruments.com/) used for:
- Signal measurement and generation
- Data acquisition and logging
- Spectrum analysis
- Lock-in amplification
- Neural network-based signal processing
- And many other lab/scientific instrument functions

## Repository Scope

The repository contains:
- **Python API examples** - Scripts and Jupyter notebooks for Python-based instrument control
- **MATLAB API examples** - MATLAB scripts for instrument automation  
- **Neural Network examples** - Deep learning applications using the Moku Neural Network instrument
- **Multi-language examples** - Demonstrations in other programming languages
- **MCC examples** - Multi-instrument Cloud Compile examples

## Key Characteristics

- This is an **examples repository**, not a library - the code is meant to be educational and demonstrative
- Examples are designed to be **copied and modified** by users for their own hardware setups
- **No example works out-of-the-box** - users must configure their device IP addresses and parameters
- The codebase prioritizes clarity and educational value over production-level robustness

## Target Users

Users working with Moku hardware devices who want to:
- Learn how to control Moku instruments programmatically
- Find starting points for their own automation scripts
- Understand best practices for various instrument types
- See examples of multi-instrument coordination
