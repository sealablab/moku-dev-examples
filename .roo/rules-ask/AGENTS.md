# Project Documentation Rules (Non-Obvious Only)

- Examples are organized by instrument type (oscilloscope, waveform generator, etc.)
- File naming follows pattern: `{instrument}_{feature}.py` or `{instrument}_{feature}.ipynb`
- All examples require IP address configuration before running
- Python API documentation: https://apis.liquidinstruments.com/python/
- MATLAB API documentation: https://apis.liquidinstruments.com/matlab/
- Neural network examples require special attention to input/output value ranges [-1, 1]
